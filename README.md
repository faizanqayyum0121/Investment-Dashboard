Investment Dashboard Project
Faizan Qayyum

This project will be a python-based investment dashboard that allows users to analyze different stocks and ETFs. 
The dashboard will use historical data about the ticker entered by the user to visualize trends and calculate useful ratios. 
The goal is to create a tool that helps users analyze a stock in one place while allowing me to strengthen my skills in 
Python, API usage, different packages(panda, numpy, etc), and building complete projects.

Planned core features:
Multi-stock comparison
Historical stock data
Risk metrics
Benchmark comparison
Portfolio analysis
Interactive UI
